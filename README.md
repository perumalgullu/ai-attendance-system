# 🎓 AI Face Recognition Attendance System

A web-based attendance management system powered by **DeepFace**, **ArcFace**, and **RetinaFace** — built with Streamlit.

---

## ✨ Features

| Feature | Description |
|---|---|
| ➕ Add Student | Register students with photo + contact details |
| 📁 Enroll Students | Generate ArcFace embeddings from photos |
| 📸 Mark Attendance | Upload class photo(s) → auto-recognise faces |
| 📜 View History | Browse past sessions, download CSVs |
| 👤 Student Profile | Per-student attendance stats & contact info |
| 📩 Notifications | Email / SMS / WhatsApp alerts for absent students |

---

## 🚀 Run Locally

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/ai-attendance-system.git
cd ai-attendance-system
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. (Optional) Set up notifications
Copy the secrets template and fill in your credentials:
```bash
cp .streamlit/secrets.toml.template .streamlit/secrets.toml
# Then edit .streamlit/secrets.toml with your email/Twilio credentials
```

### 5. Run the app
```bash
streamlit run app.py
```

---

## ☁️ Deploy on Streamlit Cloud (Free)

1. Push your code to a **public GitHub repo**
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**
3. Select your repo, branch (`main`), and set **Main file path** to `app.py`
4. Under **Advanced settings → Secrets**, paste the contents of your `secrets.toml` (email/Twilio credentials)
5. Click **Deploy** 🎉

> ⚠️ **Note:** Streamlit Cloud has no webcam access. Attendance is marked by **uploading class photos**.  
> For live webcam support, run the app locally.

## 🔧 How It Works

```
Add Student  →  student_database/<id>/photo.jpg
                contacts.json updated

Enroll       →  DeepFace.represent() called for each photo
                ArcFace embeddings saved to student_embeddings.pkl

Mark         →  Upload class photo
                detect_and_embed_faces() extracts all faces
                Cosine distance compared to known embeddings
                Match if distance < 0.40  →  marked Present
                Remaining students  →  marked Absent

Notify       →  Email + SMS + WhatsApp sent to absent students
```

## ⚙️ Configuration

| Constant | Default | Description |
|---|---|---|
| `COSINE_THRESHOLD` | `0.40` | Face match sensitivity (lower = stricter) |
| `EMBED_FILE` | `student_embeddings.pkl` | Where embeddings are stored |
| `DB_FOLDER` | `student_database` | Root folder for student photos |

## 🔒 Privacy Note

Student photos and embeddings are stored **locally** in your deployment environment.  
No data is sent to any third-party AI service — all face recognition runs **on-device**.
